## 🖥️ Основы работы с CLI

### Структура команд
- **Иерархическая**: команды организованы в дерево разделов (`/ip`, `/interface`, `/system` и т.д.)
- **Регистронезависимая**: `IP` и `ip` работают одинаково
- **Автодополнение**: клавиша `[Tab]` — ваш лучший друг
- **Справка**: `?` или `F1` показывают доступные команды

### Навигация
| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `/` | Перейти в корень из любого места | `/ip route print` |
| `..` | Подняться на уровень вверх | `..` (из `/ip route` в `/ip`) |
| `[раздел]` | Войти в раздел | `interface` (из корня в `/interface`) |
| `quit` / `exit` | Выйти из консоли | `quit` |

**Пример навигации:**
```
[admin@MikroTik] > /ip route
[admin@MikroTik] /ip/route> .. 
[admin@MikroTik] /ip> 
```

## 📁 Команды для работы с файлами и конфигурацией

### `export` — Сохранение конфигурации
Создает скрипт для восстановления настроек.

| Синтаксис | Описание | Пример |
| :--- | :--- | :--- |
| `export` | Показать конфигурацию на экране | `/export` |
| `export file=<имя>` | Сохранить в файл | `/export file=my-backup` |
| `export compact` | Без пустых строк | `/export compact file=mini` |
| `export from=<раздел>` | Экспортировать только раздел | `/ip firewall export file=fw` |
| `export verbose` | Показать все параметры (включая дефолтные) | `/interface export verbose` |

**Примеры:**
```bash
# Полный бэкап конфигурации
[admin@hAP] > /export file=backup-2026-07-12

# Бэкап только правил файрвола
[admin@hAP] > /ip firewall export file=firewall-rules

# Бэкап без комментариев
[admin@hAP] > /export compact file=clean-config
```

### `import` — Загрузка конфигурации
Выполняет команды из файла.

| Синтаксис | Описание | Пример |
| :--- | :--- | :--- |
| `import file=<имя>` | Выполнить файл | `/import file=my-backup.rsc` |
| `import file=<имя> verbose` | Показывать выполняемые команды | `/import file=script.rsc verbose` |

**Примеры:**
```bash
# Восстановить конфигурацию
[admin@hAP] > /import file=backup.rsc

# Выполнить скрипт с отображением прогресса
[admin@hAP] > /import file=setup.rsc verbose
```

### `file` — Управление файлами
Работа с файловой системой роутера.

| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `print` | Показать файлы | `file print` |
| `print detail` | Подробная информация | `file print detail` |
| `remove` | Удалить файл | `file remove old-config.rsc` |
| `move` | Переместить файл | `file move backup.rsc /hotspot/` |
| `copy` | Скопировать файл | `file copy backup.rsc backup2.rsc` |
| `set` | Изменить свойства | `file set backup.rsc contents="new text"` |
| `find` | Найти файлы | `file find name~".npk"` |

**Примеры:**
```bash
# Показать все файлы
[admin@hAP] > file print
# NAME                    TYPE                  SIZE  
# backup-2026-07-12.rsc   .rsc file             1523  
# routeros-7.23.2-arm64   .npk file          12345678

# Найти файлы обновлений
[admin@hAP] > file find where name~".npk"
; * 1

# Удалить старый файл обновления
[admin@hAP] > file remove routeros-7.22.0-arm64.npk

# Посмотреть содержимое текстового файла
[admin@hAP] > file print file=config.txt
```

## 📊 Команды для работы с переменными и данными

### `put` — Вывод данных на экран
Печатает значения в консоли.

| Синтаксис | Описание | Пример |
| :--- | :--- | :--- |
| `put <значение>` | Вывести значение | `:put "Hello"` |
| `put [команда]` | Вывести результат команды | `:put [/interface get ether1 name]` |
| `put $<переменная>` | Вывести переменную | `:put $myvar` |

**Примеры:**
```bash
[admin@hAP] > :put "Hello World"
Hello World

[admin@hAP] > :put [/system resource get uptime]
1d2h3m

[admin@hAP] > :put (1+2+3)
6
```

### `global` — Глобальные переменные
Доступны из любого места и скрипта.

| Синтаксис | Описание | Пример |
| :--- | :--- | :--- |
| `global <имя> [значение]` | Создать/изменить | `:global myvar "Hello"` |
| `global <имя>` | Показать значение | `:put $myvar` |
| `global` | Показать все глобальные переменные | `environment print` |

**Примеры:**
```bash
[admin@hAP] > :global admin "admin@example.com"
[admin@hAP] > :put $admin

[admin@hAP] > :global count 0
[admin@hAP] > :set count ($count + 1)
[admin@hAP] > :put $count
1
```

### `local` — Локальные переменные
Доступны только внутри скрипта или функции.

| Синтаксис | Описание | Пример |
| :--- | :--- | :--- |
| `local <имя> [значение]` | Создать локальную | `:local x 10` |
| `local <имя>` | Без значения (пусто) | `:local name` |

**Примеры:**

```bash
# Внутри скрипта
:local i 0
:while ($i < 5) do={
  :put $i
  :set i ($i+1)
}
```

### Преобразование типов данных

| Команда | Назначение | Пример |

| `len` | Длина строки/массива | `:put [:len "Hello"]` → 5 |

**Примеры преобразований:**
```bash
[admin@hAP] > :local num [:tonum "42"]

[admin@hAP] > :put $time
1h30m
```

## 🔄 Команды управления потоком выполнения

### `if` — Условное выполнение

| Синтаксис | Описание | Пример |
| :--- | :--- | :--- |
| `if (<условие>) do={...}` | Выполнить если true | `:if (1=1) do={:put "Ok"}` |
| `if (<условие>) do={...} else={...}` | С else-веткой | `:if (1=2) do={:put "Yes"} else={:put "No"}` |

**Операторы сравнения:**
- `=` — равно
- `!=` — не равно
- `>` — больше
- `<` — меньше
- `>=` — больше или равно
- `<=` — меньше или равно
- `~` — содержит (только в `where`)

**Примеры:**
```bash
# Проверка интернета
:local ping [/ping 8.8.8.8 count=1]
:if ($ping = 1) do={
  /log info "Internet is UP"
} else={
  /log warning "Internet is DOWN"
}

# Проверка значения
:local memory [/system resource get free-memory]
:if ($memory < 100000000) do={
  /log warning "Low memory!"
}

# Комплексное условие
:if ($a > 10 && $b < 20) do={
  :put "Condition met"
}
```

### `for` — Цикл с диапазоном

| Синтаксис | Описание | Пример |
| :--- | :--- | :--- |
| `for <var> from=<число> to=<число> do={...}` | Цикл от до | `:for i from=1 to=10 do={:put $i}` |
| `for <var> from=<число> to=<число> step=<шаг>` | С шагом | `:for i from=0 to=10 step=2 do={:put $i}` |

**Примеры:**
```bash
# Вывести числа от 1 до 5
[admin@hAP] > :for i from=1 to=5 do={:put $i}
1
2
3
4
5

# Создать 10 пользователей
:for i from=1 to=10 do={
  /user add name="user$i" password="pass$i" group=read
  :put "Added user$i"
}

# Четные числа
:for i from=2 to=20 step=2 do={:put $i}
```

### `foreach` — Цикл по элементам массива

| Синтаксис | Описание | Пример |
| :--- | :--- | :--- |
| `foreach <var> in=<массив> do={...}` | Перебор элементов | `:foreach i in=[1,2,3] do={:put $i}` |

**Примеры:**
```bash
# Перебор интерфейсов
:foreach i in=[/interface find where name~"ether"] do={
  :local name [/interface get $i name]
  :local status [/interface get $i running]
  :put "$name is $status"
}

# Перебор IP-адресов
:foreach addr in=[/ip address find] do={
  :put [/ip address get $addr address]
}

# Перебор строк
:foreach word in=["one","two","three"] do={:put $word}
```

### `while` — Цикл с условием

| Синтаксис | Описание | Пример |
| :--- | :--- | :--- |
| `while (<условие>) do={...}` | Цикл пока true | `:while ($i < 5) do={:put $i; :set i ($i+1)}` |

**Примеры:**
```bash
# Ждать появления интерфейса
:local timeout 10
:while ([/interface get pppoe-out1 running] = false && $timeout > 0) do={
  :delay 1s
  :set timeout ($timeout - 1)
  :put "Waiting for PPPoE... $timeout"
}
:if ($timeout > 0) do={
  :put "PPPoE is up!"
} else={
  :put "PPPoE timeout!"
}

# Бесконечный цикл с проверкой
:local i 0
:while ($i < 10) do={
  :put $i
  :set i ($i+1)
  :delay 1s
}
```

### `break` / `continue` — Управление циклами

| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `break` | Выйти из цикла | `:if ($i = 5) do={:break}` |
| `continue` | Перейти к следующей итерации | `:if ($i = 3) do={:continue}` |

**Примеры:**
```bash
# break - остановить на 5
:for i from=1 to=10 do={
  :if ($i = 5) do={:break}
  :put $i
}
# Выведет: 1,2,3,4

# continue - пропустить 3
:for i from=1 to=5 do={
  :if ($i = 3) do={:continue}
  :put $i
}
# Выведет: 1,2,4,5
```

### `do` — Блок выполнения

| Синтаксис | Описание | Пример |
| :--- | :--- | :--- |
| `do { ... }` | Выполнить блок | `do { /interface enable ether1; /log info "Enabled" }` |
| `do {} while (условие)` | Выполнить, потом проверить | `do { :put $i; :set i ($i+1) } while ($i < 5)` |

**Примеры:**
```bash
# Блок с несколькими командами
do {
  /interface disable ether2
  /interface disable ether3
  /log info "Disabled ports"
}

# Выполнить и проверить
:local i 0
do {
  :put $i
  :set i ($i+1)
} while ($i < 3)
```

### `onerror` — Обработка ошибок

| Синтаксис | Описание | Пример |
| :--- | :--- | :--- |
| `onerror={...} do={...}` | Перехват ошибок | `onerror={:put "Error!"} do={/interface enable nonexis}` |
| `error` | Создать ошибку | `:error "Something went wrong"` |

**Примеры:**
```bash

  :error "Interface ether1 not found!"
}
```

### `return` — Возврат значения

| Синтаксис | Описание | Пример |

## 🔍 Шпаргалка по поиску и фильтрации

### Почему `find` без `where` ищет только точное совпадение
```bash
[admin@hAP] > /interface find name="ether1"    # ✅ Найдет
[admin@hAP] > /interface find name="ether"     # ❌ Нет точного совпадения
[admin@hAP] > /interface find name="eth*"      # ❌ Маски не работают
```

---

### Операторы фильтрации

| Оператор | Значение | Пример |
| :--- | :--- | :--- |
| `=` | Равно | `name="ether1"` |
| `!=` | Не равно | `name!="ether1"` |
| `~` | Содержит | `name~"ether"` |
| `!~` | Не содержит | `name!~"vlan"` |
| `>` | Больше | `mtu>1500` |
| `<` | Меньше | `mtu<1500` |
| `>=` | Больше или равно | `mtu>=1500` |
| `<=` | Меньше или равно | `mtu<=1500` |

---

### Примеры поиска

| Что ищем | Команда |
| :--- | :--- |
| Точное имя | `/interface find name="ether1"` |
| По части имени | `/interface find where name~"ether"` |
| Запущенные интерфейсы | `/interface find where running` |
| Все ether-интерфейсы | `/interface find where name~"ether"` |
| Все кроме bridge | `/interface find where name!="bridge"` |
| По MAC-адресу | `/interface find where mac-address~"D0:EA"` |
| MTU больше 1500 | `/interface find where mtu>1500` |
| С несколькими условиями | `/interface find where name~"ether" and running` |
| Показать результат | `/interface print where name~"ether"` |

---

### Использование результатов в переменных

```bash
# Сохранить в переменную
:local eth1 [/interface find name="ether1"]
:put $eth1  # 0

# Изменить все ether-интерфейсы
/interface set [/interface find where name~"ether"] mtu=1500

# Отключить все wifi
/interface disable [/interface find where name~"wifi"]

# Включить все кроме ether1
/interface enable [/interface find where name!="ether1"]
```

---

### Поиск в разных разделах

```bash
# IP-адреса
/ip address find where address~"192.168"
/ip address find where interface="bridge"
/ip address find where dynamic

# Маршруты
/ip route find where dst-address="0.0.0.0/0"
/ip route find where active
/ip route find where gateway~"pppoe"

# Логи
/log find where topics~"pppoe" and message~"error"
/log find where time>=[/system clock get time] - 5m

# Правила файрвола
/ip firewall filter find where chain="forward"
/ip firewall nat find where action="masquerade"

# Пользователи
/user find where name="admin"
/user find where group="full"
```

## 💡 Полезные советы

1. **Используйте `Tab` для автодополнения** — экономит время и избегает ошибок
2. **`?` после команды** — показывает доступные подкоманды
3. **Обратные слэши `\`** — для переноса длинных команд
4. **Точка с запятой `;`** — разделяет команды в одной строке
5. **`#`** — комментарии в скриптах
6. **`$`** — обращение к переменной
7. **`[]`** — выполнение команды внутри выражения
