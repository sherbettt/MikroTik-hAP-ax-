## Обновление RouterOS на MikroTik hAP ax³

Ниже приведены все способы обновления операционной системы вашего роутера. 
MikroTik hAP ax³ имеет архитектуру **arm64** (подтверждено командой `/system resource print`), поэтому для ручного обновления нужны файлы с суффиксом `arm64.npk` .

---

### 🔍 Перед обновлением: узнайте архитектуру

```bash
[admin@hAP] > /system resource print
```
В строке `architecture-name` будет указана архитектура (у вас — `arm64`) .

---

## Способ 1: Автоматическое обновление через WinBox (с сервера MikroTik)

Самый простой способ, роутер сам скачивает файлы с официальных серверов .

1. В WinBox перейдите в **System → Packages**
2. Нажмите кнопку **Check For Updates**
3. Если новая версия доступна, появятся кнопки:
   - **Download** — только скачать (перезагрузка вручную)
   - **Download & Install** — скачать и автоматически перезагрузить 
4. После перезагрузки проверьте версию в **System → Resources**

> ⚠️ **Важно:** Роутер должен иметь доступ в интернет (HTTPS, порт 443), чтобы скачивать обновления .

---

## Способ 2: Автоматическое обновление через SSH/CLI (с сервера)

Подходит для удалённого управления или автоматизации .

Подключитесь по SSH и выполните:

```bash
[admin@hAP] > /system package update check-for-updates once
```

Если доступна новая версия, установите её:

```bash
[admin@hAP] > /system package update install
```

Роутер скачает обновление и перезагрузится .

**Автоматизация через скрипт** (можно добавить в планировщик) :

```bash
[admin@hAP] > /system package update
check-for-updates once
:delay 3s;
:if ( [get status] = "New version is available") do={ install }
```

## Способ 3: Ручное обновление через WinBox (загрузка NPK-файла)

Подходит, если роутер не имеет доступа в интернет или вы хотите обновиться до конкретной версии .

### Шаг 1: Скачайте файл прошивки
1. Перейдите на [mikrotik.com/software](https://mikrotik.com/software)
2. Выберите архитектуру **ARM64** 
3. Скачайте основной пакет: **routeros-7.23.2-arm64.npk**
4. Если у вас установлены дополнительные пакеты (например, `wifi`), скачайте их из архива `all_packages-arm64-7.23.2.zip` 

### Шаг 2: Загрузите файл на роутер
1. В WinBox перейдите в **Files**
2. **Перетащите** скачанный `.npk` файл мышкой в окно Files 
3. Файл должен оказаться в **корневой папке** (не внутри `hotspot` или других папок)
4. проверить в терминале можно командой:
   ```bash
   [admin@hAP] > /file/ print
   ```

### Шаг 3: Перезагрузите роутер
```bash
[admin@hAP] > /system reboot
```
После перезагрузки пакет установится автоматически .

---

## Способ 4: Ручное обновление через SSH/SCP (загрузка NPK-файла)

Подходит для продвинутых пользователей и автоматизации .

### Шаг 1: Скопируйте файл на роутер

С терминала вашего компьютера (Linux/macOS/WSL):

```bash
scp routeros-7.23.2-arm64.npk admin@192.168.88.1:
```

> **Примечание:** Файл будет скопирован в корневую папку Files на роутере .

### Шаг 2: Перезагрузите роутер

```bash
ssh admin@192.168.88.1 '/system reboot'
```

После перезагрузки обновление установится .

---

## Способ 5: Автоматическая установка (файл .auto.npk)

Если переименовать файл, роутер установит обновление **без перезагрузки вручную** .

1. Переименуйте файл:
   ```
   routeros-7.23.2-arm64.auto.npk
   ```
2. Загрузите его любым способом (WinBox, SCP, FTP)
3. Роутер автоматически перезагрузится и установит обновление 

---

## 📌 После обновления: обновите загрузчик (RouterBOOT)

**Это важный шаг!** После обновления RouterOS рекомендуется обновить и bootloader .

### Через CLI:
```bash
[admin@hAP] > /system routerboard upgrade
[admin@hAP] > /system reboot
```

### Через WinBox:
1. Перейдите в **System → RouterBOARD**
2. Нажмите **Upgrade**
3. Подтвердите и перезагрузитесь 

---

## ⚠️ Важные моменты

| Момент | Пояснение |
| :--- | :--- |
| **Архитектура** | Убедитесь, что скачиваете файлы для `arm64` (ваша архитектура)  |
| **Дополнительные пакеты** | Если установлены пакеты (`wifi`, `wireless` и др.), их тоже нужно загрузить, иначе обновление может не установиться  |
| **Поэтапное обновление** | При переходе с очень старых версий может потребоваться обновление через промежуточную версию  |
| **Проверка после обновления** | Всегда проверяйте: `/system resource print` и `/system package print` |
